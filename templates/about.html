About CyberToolkit

Cybersecurity Toolkit bundles the most common utilities used by ethical hackers and security engineers into a single, hardened Flask application.

Included tools
  • Hash generator (MD5, SHA1, SHA224, SHA256, SHA384, SHA512)
  • Base64 encoder / decoder
  • Cryptographically secure password generator with entropy analysis
  • Threaded TCP port scanner with service detection
  • WHOIS domain lookup
Security disclaimer

This toolkit is intended for educational purposes and authorized security testing only. Do not scan systems you do not own or have explicit permission to test.
